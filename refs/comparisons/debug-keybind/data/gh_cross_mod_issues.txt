=============== TreyRuffy/BetterF3#185
[Bug]: Crashes if DebugKeybind mod rebinds f3 to specific keys
state: open created: 2025-11-09 updated: 2025-11-09 labels: 
### Describe the Bug

If the [Debug Keybind](https://modrinth.com/mod/debug-keybind) mod is used to rebind the debug key (Originally f3) is to certain keys, pressing it causes the game to crash. Specifically, it crashes when the debug keybind is bound to something that's intended to be a debug action (Eg: B for Show HItboxes, V, E, etc)

It _doesn't_ crash if f3 is rebound and BetterF3 is _not_ installed. I'm unsure which mod exactly is causing the problem, but the crash log is only mentioning BetterF3 so I'm reporting it here.

### Steps to Reproduce

1. Install Debug Keybind and BetterF3.
2. Rebind the "Debug Key" to B (Or any other key that's originally a Debug Action).
(It doesn't matter if "Show Hitboxes" (Originally B) is changed to another key or not).
4. Press B, and the game crashes.

### Expected Behavior

Not to crash
