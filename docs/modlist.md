# Mod List

- Installed from CurseForge: The Twilight Forest, IceAndFire Community Edition, Catalogue, Solix, AllTheLeaks, JEI/EMI Optimizations, Weather Refined, All Japanese Translate. All others come from Modrinth.
- A missing link has no icon. `-` in Last Updated means no public repository.
- Last Updated is the last commit on the repository's default branch (Shields.io). It is not a release date.
- The right-hand Links column holds the official site (`Site`, at most one) and every wiki or documentation page found, one link per wiki, labeled by what it is: `Official Wiki` and `Official Docs` (run or linked by the author), `Fandom Wiki`, `wiki.gg Wiki`, `Miraheze Wiki`, `FTB Wiki`, `Minecraft Japan Wiki`, or the wiki's own name. A wiki need not be official. Repository pages are not repeated there. `-` means none was found.
